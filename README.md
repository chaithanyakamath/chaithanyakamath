## Featured Projects

### HealthSync
Full-stack personal health management platform with JWT authentication, doctor and appointment tracking, and medical document storage via Cloudinary. Includes an AI pharmacy assistant that parses prescription images (Gemini AI) and looks up drug info/alternatives through the OpenFDA database.

`JavaScript` `Node.js` `Express` `MongoDB` `JWT Auth` `Gemini AI`

[View Repository](https://github.com/chaithanyakamath/healthSync)

### DealRoom
Real-time AI negotiation assistant, architected as a pipeline of focused agents rather than one giant prompt: a setup strategist builds a playbook before the conversation, a live "whisper" engine analyzes the other party's latest turn during the call, and a simulator predicts likely negotiation paths. React/Vite client, Express + Socket.io backend, containerized with Docker.

`React` `Vite` `Express` `Socket.io` `Docker` `LLM Agents`

[View Repository](https://github.com/chaithanyakamath/dealRoom)

### Cloudinary SaaS
AI-powered media SaaS for uploading, transforming, and managing images/video through Cloudinary, with a Next.js frontend and Prisma/NeonDB backend.

`Next.js` `TypeScript` `Prisma` `NeonDB` `Cloudinary`

[View Repository](https://github.com/chaithanyakamath/cloudinarySaas) · [Live Demo](https://cloudinary-saas-mu.vercel.app)

### Deep Learning From Scratch
Core neural network architectures — MLP, sparse autoencoder, and a restricted Boltzmann-style energy-based model — implemented with plain NumPy (no TensorFlow/PyTorch) to work through forward propagation, backpropagation, and gradient descent by hand, evaluated on MNIST. A separate PyTorch repo covers CNN/RNN/GAN implementations on Fashion-MNIST and time-series data.

`Python` `NumPy` `PyTorch`

[View Repository](https://github.com/chaithanyakamath/deeplearningTASK1)
